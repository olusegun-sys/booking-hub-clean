## 🎯 Project Vision & Mission

### What We're Building
**Booking Hub** is a multi-tenant booking management platform for Nigerian hospitality businesses. Think of it as **"Shopify for hospitality"** - not a marketplace like Booking.com, but a platform where each business gets their own branded booking page, accepts payments (Paystack or pay-at-venue), receives automated email notifications, and tracks all bookings in a real-time dashboard.

**Now part of Plazzaa:** The platform is being integrated into the larger Plazzaa ecosystem as the "Plazzaa for Business" solution - a comprehensive business management tool for hospitality businesses.

### The Problem We're Solving
Nigerian hospitality businesses (hotels, sports facilities, event venues) struggle with:
- ❌ No online presence or booking system
- ❌ Manual booking management (paper, WhatsApp, phone calls)
- ❌ No way to accept online payments
- ❌ No analytics or insights about their business
- ❌ Expensive custom development costs

### Our Solution
- ✅ Free branded booking page for each business
- ✅ Real-time booking management dashboard
- ✅ Paystack integration for online payments
- ✅ Automated email notifications for bookings
- ✅ Analytics and insights dashboard
- ✅ Mobile-first design (Nigeria is mobile-first!)
- ✅ Shareable booking links for WhatsApp and social media

### Data Flow
1. **User** visits business booking page → selects room/dates → chooses payment method
2. **Frontend** sends booking request to backend API
3. **Backend** validates → creates booking in database → triggers email
4. **If Paystack**: redirects to payment → verifies on callback → confirms booking
5. **If Pay at Venue**: creates booking immediately → sends confirmation email
6. **Business Owner** sees booking in dashboard → can manage/update status

## 📁 Database Schema (Complete)

### Tables Structure

```sql
-- Users Table
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  full_name VARCHAR(255),
  role VARCHAR(50) DEFAULT 'owner',
  business_id UUID REFERENCES businesses(id),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Businesses Table
CREATE TABLE businesses (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id),
  name VARCHAR(255) NOT NULL,
  slug VARCHAR(255) UNIQUE NOT NULL,
  business_type VARCHAR(100),
  description TEXT,
  email VARCHAR(255),
  phone VARCHAR(50),
  address TEXT,
  state VARCHAR(100),
  city VARCHAR(100),
  logo_url TEXT,
  cover_url TEXT,
  about TEXT,
  story_image TEXT,
  status VARCHAR(50) DEFAULT 'pending',
  is_active BOOLEAN DEFAULT TRUE,
  booking_limit INTEGER DEFAULT 50,
  current_booking_count INTEGER DEFAULT 0,
  subscription_status VARCHAR(50) DEFAULT 'free',
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Rooms Table
CREATE TABLE rooms (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  business_id UUID REFERENCES businesses(id) ON DELETE CASCADE,
  name VARCHAR(255) NOT NULL,
  description TEXT,
  price DECIMAL(10,2) NOT NULL,
  capacity INTEGER,
  amenities TEXT[],
  images TEXT[],
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Bookings Table
CREATE TABLE bookings (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  business_id UUID REFERENCES businesses(id) ON DELETE CASCADE,
  room_id UUID REFERENCES rooms(id) ON DELETE CASCADE,
  booking_reference VARCHAR(255) UNIQUE NOT NULL,
  customer_name VARCHAR(255) NOT NULL,
  customer_email VARCHAR(255) NOT NULL,
  customer_phone VARCHAR(50),
  check_in DATE NOT NULL,
  check_out DATE NOT NULL,
  guests INTEGER DEFAULT 1,
  total_price DECIMAL(10,2) NOT NULL,
  payment_method VARCHAR(50),
  payment_status VARCHAR(50) DEFAULT 'pending',
  paystack_reference VARCHAR(255),
  status VARCHAR(50) DEFAULT 'pending',
  notes TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Staff Table
CREATE TABLE staff (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  business_id UUID REFERENCES businesses(id) ON DELETE CASCADE,
  email VARCHAR(255) NOT NULL,
  name VARCHAR(255) NOT NULL,
  role VARCHAR(100),
  password_hash VARCHAR(255) NOT NULL,
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Admin Users Table
CREATE TABLE admin_users (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  password VARCHAR(255),
  full_name VARCHAR(255),
  created_at TIMESTAMP DEFAULT NOW()
);

-- Admin Sessions Table
CREATE TABLE admin_sessions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  admin_id UUID REFERENCES admin_users(id),
  token VARCHAR(255) UNIQUE NOT NULL,
  expires_at TIMESTAMP NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Business Sessions Table
CREATE TABLE business_sessions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  business_id UUID REFERENCES businesses(id),
  token VARCHAR(255) UNIQUE NOT NULL,
  expires_at TIMESTAMP NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Subscription Upgrades Table
CREATE TABLE subscription_upgrades (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  business_id UUID REFERENCES businesses(id) ON DELETE CASCADE,
  plan VARCHAR(50) NOT NULL,
  amount DECIMAL(10,2) NOT NULL,
  payment_reference VARCHAR(255) UNIQUE NOT NULL,
  status VARCHAR(50) DEFAULT 'pending',
  notes TEXT,
  verified_at TIMESTAMP,
  verified_by UUID,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

## 🐛 Complete Bug Fix History

### Critical Issues Fixed

#### 1. Git Repository Corruption
- **Problem**: Repository became corrupted, couldn't push/pull
- **Root Cause**: Large files, interrupted operations
- **Solution**: Fresh clone from GitHub, re-applied changes
- **Status**: ✅ FIXED

#### 2. Admin Login Demo Credentials Showing
- **Problem**: Demo credentials displayed on login form
- **Root Cause**: Found in `App.jsx` SimpleAdminLogin component
- **Solution**: Removed demo credentials, added "Contact admin" message
- **Status**: ✅ FIXED

#### 3. Password Toggle Not Working
- **Problem**: Eye icon didn't toggle password visibility
- **Root Cause**: Missing `showPassword` state in both login components
- **Solution**: Added `showPassword` state and Eye/EyeOff icons with click handlers
- **Status**: ✅ FIXED

#### 4. AdminLogin ReferenceError
- **Problem**: `React is not defined` error
- **Root Cause**: Missing React import in AdminLogin component
- **Solution**: Added `import React from 'react'`
- **Status**: ✅ FIXED

#### 5. AdminDashboard Build Failures
- **Problem**: Syntax errors during build
- **Root Cause**: Extra closing parenthesis, missing brackets
- **Solution**: Fixed syntax errors, proper formatting
- **Status**: ✅ FIXED

#### 6. Render Deployment Failing
- **Problem**: Build failures on Render
- **Root Cause**: Syntax errors, incorrect file paths
- **Solution**: Fixed all syntax errors, proper Git push
- **Status**: ✅ FIXED

#### 7. Home Button Missing
- **Problem**: No navigation back to homepage from admin dashboard
- **Root Cause**: Oversight in UI design
- **Solution**: Added Home button to AdminDashboard header
- **Status**: ✅ FIXED

#### 8. Mobile Responsiveness Issues
- **Problem**: Many components not responsive on mobile
- **Root Cause**: Desktop-first design without proper breakpoints
- **Solution**: Added mobile-specific styles, bottom nav on mobile
- **Status**: ✅ FIXED

#### 9. Email Notifications Blocked (CURRENT ISSUE)
- **Problem**: Only test emails work (`olusegun@luminara.io`, `segzyblink170@gmail.com`)
- **Root Cause**: Resend test mode requires domain verification
- **Solution**: Need to purchase domain (`myplazzaa.com`) and verify in Resend
- **Status**: 🔴 **BLOCKED** - Awaiting domain from Yannick

#### 10. Image Upload Not Displaying
- **Problem**: Users could select images but they wouldn't display
- **Root Cause**: Parent component didn't refresh after upload
- **Solution**: Added `onRefresh` callback to ImageUpload component
- **Status**: ✅ FIXED

#### 11. Custom Domain Verification
- **Problem**: Domain verification was simplified without actual DNS checking
- **Root Cause**: No DNS TXT record verification implemented
- **Solution**: Created `dnsService.js` with actual DNS TXT record verification
- **Status**: ✅ FIXED

#### 12. isMobile ReferenceError (CRITICAL - FIXED)
- **Problem**: `isMobile is not defined` causing blank page
- **Root Cause**: `isMobile` variable used but never declared in `UnifiedBookingPage.jsx`
- **Solution**: Added `useIsMobile()` custom hook with SSR support
- **Status**: ✅ FIXED

#### 13. Booking Modal - paymentMethod Not Defined (FIXED)
- **Problem**: `paymentMethod is not defined` error when submitting booking
- **Root Cause**: paymentMethod state missing from BookingFormModal
- **Solution**: Added proper state declaration
- **Status**: ✅ FIXED

#### 14. Booking Modal - Icon Import Errors (FIXED)
- **Problem**: `User is not defined`, `Wallet is not defined`, `Loader2 is not defined`
- **Root Cause**: Icons used but not imported
- **Solution**: Replaced with `Users`, `CreditCard`, and `Loader` (already imported)
- **Status**: ✅ FIXED

#### 15. Admin Token Key Mismatch (FIXED)
- **Problem**: AdminDashboard 401 Unauthorized
- **Root Cause**: AdminLogin stores token as `auth_token` but AdminDashboard looked for `admin_token`
- **Solution**: Added `getToken()` helper that tries all possible token keys
- **Status**: ✅ FIXED

#### 16. CSS Syntax Error on Render (FIXED)
- **Problem**: `[postcss] Unknown word ""` build failure
- **Root Cause**: Malformed CSS from PowerShell echo commands
- **Solution**: Cleaned up CSS file, removed duplicates
- **Status**: ✅ FIXED
