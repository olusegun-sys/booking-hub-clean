# Booking Hub - Complete Project Overview (UPDATED)

## Project Vision
A multi-tenant booking management platform for Nigerian hospitality businesses (hotels, sports facilities, event venues). Each business gets their own branded booking page, accepts payments via Paystack or pay-at-venue, receives automated email notifications, and tracks all bookings in a real-time dashboard.

**Think Shopify for hospitality — not a marketplace like Booking.com.**

## The Golden Rule (From Master Prompt)

> **"Design for the worst-case scenario first (375px mobile), then expand for desktop. Desktop is 'mobile + more space' not 'desktop - something broke.'"**

Every solution must answer:
1. "What does the user actually need at this moment?"
2. "What's the job to be done?"
3. "How do I remove friction?"
